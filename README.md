## 🚀 Quick Start for Developers

### Run Locally
No heavy dependencies, Node.js build steps, or frameworks needed! It runs cleanly on any standard static HTTP server or Python:

`ash
# Using Python
python -m http.server 8000

# Or with VS Code Live Server extension
# Right-click index.html -> 'Open with Live Server'
`

Visit: http://localhost:8000

## ⚙️ GitHub Pages Deployment

1. Navigate to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment**:
   - **Source**: Select Deploy from a branch
   - **Branch**: Select main and folder / (root)
   - Click **Save**.
3. Within 1–2 minutes, the site is live at https://dhanasekaran865-gif.github.io/CCIC-WEBSITE/.
